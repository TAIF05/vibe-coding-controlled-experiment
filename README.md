# Vibe-coding-experiment

This repository contains the source code collected from the experimental study
comparing Vibe Coding with Traditional Coding.

## Experiment Overview

The study investigates the effect of Vibe Coding on programming performance
compared with Traditional Coding.

The experiment focuses on the following research questions:

- RQ1: Does Vibe Coding affect task completion speed compared to traditional coding?
- RQ2: Does Vibe Coding improve the rate of completing complex programming tasks?
- RQ3: Does Vibe Coding affect debugging effort and the ease of handling programming errors?
- RQ4: Does Vibe Coding reduce cognitive load during programming tasks?
  
## Experimental Groups

The study included 10 university students divided equally into two groups:

- **Traditional Coding:** 5 participants
- **Vibe Coding:** 5 participants

Participants completed programming tasks with different levels of difficulty.
